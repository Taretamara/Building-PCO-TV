# PCO TV — Accessibility Checklist (Phase 1 gate, PRD §22)

Every slice must pass these before merge. TV is shared, distant viewing.

## Focus (remote-only)
- [ ] Gold focus ring visible on every focusable; never color-only (scale 1.05 + ring).
- [ ] Focus never lost: arrows clamp, Back always lands on parent tab.
- [ ] Focus memory per rail/screen (re-entry restores position).
- [ ] Full walkthrough possible with D-pad only (no pointer).

## Readability (10-foot)
- [ ] Body ≥17px (min 20px at 10ft), cards ≥15px, meta ≥13px; hero 44px.
- [ ] Contrast AA minimum (text #F7F1E6 on bg #0E0C0A; muted #C9BCA6 for secondary only).
- [ ] No essential info in artwork alone (title/speaker/duration as text).

## Playback
- [ ] Clear Play/Pause/Prev/Next, captions toggle where available.
- [ ] Resume label states time ("Resume · 12 min in"), not just "Continue".
- [ ] Music keeps playing with mini-player + Album/Artist path (§12).

## Language & motion
- [ ] Straightforward wording; no LoveWorld jargon without context (§2 secondary audience).
- [ ] Focus transitions 150–250ms; no autoplay motion required to navigate.
- [ ] Empty states always offer a next step ("Nothing is live" → Upcoming/Recent/Recommended).

## Content quality gate (§25)
- [ ] Every item: artwork + title + description + speaker + program + category before publish.
